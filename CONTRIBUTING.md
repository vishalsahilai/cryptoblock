# Contributing

Fork, create a branch, install with `pnpm install --frozen-lockfile`, and run `pnpm test` and `pnpm build`. Describe behavior changes, evidence and verification limits in your pull request. Keep credentials, user data and generated artifacts out of commits.

Preserve closed-candle/no-lookahead rules, immutable forecasts, exact-target outcome verification, private ownership checks and clear live/demo labels. Never fill sparse rankings or missing performance history with fabricated data. Append database migrations; do not rewrite applied migrations. Numerical changes need independent fixtures or invariants, not just tests that reproduce the implementation.

The model is experimental. Do not advertise unmeasured accuracy or profitability, or imply affiliation with another platform.
